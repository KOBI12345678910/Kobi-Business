# האתר הבינלאומי של קובי אלקיים נדל"ן – מנוע הדפים

מחולל סטטי (Node.js, בלי תלויות) שבונה את דפי האתר לקונים מחו"ל באנגלית, צרפתית ורוסית.

## הרצה

```
node build.js                 # בניית תצוגה מקדימה (קישורים יחסיים, noindex) לתיקייה dist/
node build.js --prod          # בניית ייצור (כתובות נקיות, פתוח לאינדוקס) לתיקייה dist-prod/
node qa.js dist               # בדיקות: כותרות ותיאורים כפולים, קישורים שבורים, hreflang, נתונים מובנים
SITE_URL=https://example.com node build.js --prod   # החלפת הדומיין שבכתובות הקנוניות ובמפות האתר
```

## מבנה

- `data/tax.js` – מדרגות מס הרכישה (תושב חוץ, עולה חדש, תושב ישראל בדירה יחידה) וחישוב לפי מדרגות.
- `data/cities.js` – נתוני הערים. כל מספר הועתק מסעיף "נתונים מקומיים מאומתים" בדף העברי המקביל באתר הראשי.
- `data/i18n-en.js`, `data/i18n-fr.js`, `data/i18n-ru.js` – כל הטקסטים והתבניות לפי שפה.
- `build.js` – רישום הדפים, hreflang, canonical, מפות אתר, robots.txt, JSON-LD וכתיבת ה-HTML.
- `qa.js` – בדיקות אוטומטיות על תיקיית בנייה.

## כללים שהמנוע שומר עליהם

- דף נבנה רק כשכל הנתונים שלו קיימים. ערך חסר לא מומצא, והשורה פשוט לא מופיעה.
- דף שמסומן `draft: true` ברישום הדפים לא נכנס למפת האתר ונשאר noindex.
- האתר נבנה ב-Vercel מהענף `global-site`: כל push לענף ואחריו פריסה חדשה מעדכנים את האתר החי.
- הוספת עיר: רשומה חדשה ב-`data/cities.js`. הוספת שפה: קובץ `data/i18n-xx.js` חדש והוספת הקוד לרשימת `LANGS` ב-`build.js`.
- מספרי המס נבדקו מול 14 דוגמאות מהדפים המאומתים באתר הראשי (9–11.11.2026).

## מה נבנה כרגע

לכל שפה: דף בית, דף שירות, 3 מדריכים, 172 דפי חישוב מס רכישה (86 מחירים × תושב חוץ / עולה חדש), 114 דפי ערים (57 ערים × 2 קהלים) ו-3 דפי אינדקס. המספר המדויק מודפס בסוף כל בנייה.
