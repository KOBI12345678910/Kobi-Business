# האתר הבינלאומי של קובי אלקיים נדל"ן – מנוע הדפים

מחולל סטטי (Node.js, בלי תלויות) שבונה את דפי האתר לקונים מחו"ל באנגלית, צרפתית, רוסית, ספרדית, גרמנית ופורטוגזית.

## הרצה

```
node build.js                 # בניית תצוגה מקדימה (קישורים יחסיים, noindex) לתיקייה dist/
node build.js --prod          # בניית ייצור (כתובות נקיות, פתוח לאינדוקס) לתיקייה dist-prod/
node qa.js dist               # בדיקות: כותרות ותיאורים כפולים, קישורים שבורים, hreflang, נתונים מובנים
SITE_URL=https://example.com node build.js --prod   # החלפת הדומיין שבכתובות הקנוניות ובמפות האתר
```

## מבנה

- `data/tax.js` – מדרגות מס הרכישה (תושב חוץ, עולה חדש, תושב ישראל בדירה יחידה) וחישוב לפי מדרגות.
- `data/cities.js` – נתוני 72 ערים. כל מספר הועתק מסעיף "נתונים מקומיים מאומתים" בדף העברי המקביל באתר הראשי.
- `data/places.js` – ירושלים, תל אביב וחיפה, ו-47 שכונות שלהן: מזהים, מקורות ומספר העובדות לכל שכונה.
- `data/places-<שפה>.js` – הטקסטים של הערים הגדולות והשכונות בכל שפה: שמות, תבניות ועובדות מתורגמות.
- `data/i18n-<שפה>.js` – שאר הטקסטים והתבניות לפי שפה.
- `build.js` – רישום הדפים, hreflang, canonical, מפות אתר, robots.txt, JSON-LD וכתיבת ה-HTML.
- `qa.js` – בדיקות אוטומטיות על תיקיית בנייה.

## כללים שהמנוע שומר עליהם

- דף נבנה רק כשכל הנתונים שלו קיימים. ערך חסר לא מומצא, והשורה פשוט לא מופיעה.
- לשכונה אין ממוצע מחירים רשמי. דף שכונה מציג את נתוני העיר ואומר זאת במפורש.
- אם בקובץ `places-<שפה>.js` חסר תרגום של עובדה, הבנייה נעצרת עם הודעת שגיאה.
- שפה שאין לה קובץ `places-<שפה>.js` נבנית בלי הערים הגדולות והשכונות.
- דף שמסומן `draft: true` ברישום הדפים לא נכנס למפת האתר ונשאר noindex.
- האתר נבנה ב-Vercel מהענף `global-site`: כל push לענף ואחריו פריסה חדשה מעדכנים את האתר החי.
- הוספת עיר: רשומה חדשה ב-`data/cities.js`. הוספת שפה: קובץ `data/i18n-xx.js` (ורצוי גם `data/places-xx.js`) והוספת הקוד לרשימת `LANGS` ב-`build.js`.
- מספרי המס נבדקו מול 14 דוגמאות מהדפים המאומתים באתר הראשי (9–11.11.2026).

- `data/urban-renewal.json` – עותק של מאגר מתחמי ההתחדשות העירונית של משרד הבינוי והשיכון (data.gov.il, עודכן 21.11.2026). `data/renewal.js` ממפה יישובים לערים באתר, ו-`data/renewal-i18n.js` מחזיק את הטקסטים בשש השפות. דף לכל מתחם, דף לכל יישוב ואינדקס.
- `data/countries.js` – מדריכים לפי מדינת מוצא (צרפת, ארה"ב, קנדה).

## מה נשאר בחוץ בכוונה

- מעלה אדומים וקצרין (וגם מתחמי ההתחדשות במעלה אדומים ובאריאל), ובירושלים: גילה, הר חומה, פסגת זאב, רמות, רמת אשכול והגבעה הצרפתית. הנתונים שלהן קיימים באתר הראשי, אבל תיאור המעמד שלהן לקונים מחו"ל מחכה לניסוח של החברה.
- תחנת הרכבת במלחה: לא נכללה, כי לא אומת שהיא פעילה היום.

## מה נבנה כרגע

לכל שפה: דף בית, דף שירות, 3 מדריכים, 172 דפי חישוב מס רכישה (86 מחירים × תושב חוץ / עולה חדש), 150 דפי ערים (75 ערים × 2 קהלים), 94 דפי שכונות (47 שכונות × 2 קהלים) ו-4 דפי אינדקס. המספר המדויק מודפס בסוף כל בנייה.
